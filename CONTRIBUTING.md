# Contributing to Quixotic

Open issues for Quixotic in [the Quixotic repository](https://github.com/linianchen666/Quixotic/issues). Include the version, platform, and steps to reproduce the issue. Use the [security reporting instructions](./.github/SECURITY.md) for private disclosure.

Keep patches focused on one problem and include the checks you ran. See the [development runbook](./docs/operations/00_development.md) and [repository guidance](./AGENTS.md) for setup and tests.

Quixotic is an independent fork of T3 Code. Keep upstream copyright and license notices with redistributed code, and follow the [upstream trademark notice](./TRADEMARK.md).
